# iPhone GPU eras

original/3G: PowerVR MBX Lite
3GS/4: PowerVR SGX535
4S: SGX543MP2
5/5c: SGX543MP3
5s/A7: PowerVR G6430, historical Apple1
6/A8: GX6450, Apple2
6s/SE1/A9: GT7600, Apple3
7/A10: PowerVR-derived A10 GPU, Apple3
8/X/A11 onward: Apple-designed GPU, Apple4+

For cheap old hardware, A9/Apple3 is a useful broad Metal baseline; A11/Apple4 is the first target with the distinctive programmable imageblock/tile-shader machinery.
