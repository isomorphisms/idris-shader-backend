# PowerVR Apple era

Early iPhone/iPad/iPod touch GPUs were Imagination PowerVR. PowerVR's tile-based deferred rendering heritage is relevant to this project, but the stable application compiler target was the public graphics API/shading language, not a PowerVR machine opcode ABI.

The hardware folders below map representative Apple SoCs/devices. Each `instructions.txt` deliberately refuses to invent private USC/microcode opcodes.
