# Apple-designed GPUs

A11 is the first iPhone SoC in this atlas with an Apple-designed GPU. The compiler-facing public target is Metal/MSL; Apple GPU-family numbers describe capability floors. Hardware opcodes are deliberately not invented.

Generations here:
- Apple4 / A11
- Apple5 / A12
- Apple6 / A13
- Apple7 / A14 and M1
- Apple8 / A15, A16 and M2
- Apple9 / A17, A18, M3 and M4
- Apple10 / A19 and M5
