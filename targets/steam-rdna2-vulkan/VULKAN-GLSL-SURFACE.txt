VULKAN GLSL SOURCE-LANGUAGE SURFACE
Baseline source language: GLSL 4.60 constrained by the Vulkan GLSL/SPIR-V environment.
Portable binary boundary: SPIR-V 1.6.
The Vulkan environment, enabled device features, and glslang validator are the acceptance authority; desktop-GL built-ins that have no Vulkan meaning are not silently assumed.

VULKAN ENVIRONMENT RULES TO KEEP EXPLICIT
all shader resources use Vulkan-compatible explicit interface/binding rules
non-opaque host data is represented through uniform/storage/push-constant interfaces rather than desktop-GL default uniforms
shader inputs/outputs use explicit locations/built-ins as required by the Vulkan environment
specialization constants map to SPIR-V specialization constants
host resource layouts and GLSL block layouts must agree byte-for-byte
features such as 64-bit arithmetic, subgroup operations, storage image formats and optional stages remain device/capability gated
legacy fixed-function / compatibility-profile GLSL is not part of this baseline
Vulkan WSI is not a shader-language feature
ray tracing, mesh/task shading and vendor extensions are not part of the baseline branch

COMPILATION ORACLE
glslangValidator/glslc with an explicitly pinned Vulkan target environment
SPIR-V validation under the corresponding Vulkan environment
SURFACE.txt SPIR-V inventory is the durable post-GLSL operation inventory
