SCOPE / COMPLETENESS
- This file lists the GLSL 4.60 core operation-name families relevant to UAM's configured desktop-core frontend.
- UAM's embedded Mesa sources are the final acceptance authority because extension predicates and UAM patches can add/remove overloads relative to a generic GLSL 4.60 implementation.
- tools/extract_uam_glsl_surface.py mechanically emits source-level built-in function and gl_* variable names from the exact UAM sources and should be diffed against this readable inventory.
