# Authoritative sources

Primary sources:

- Metal Feature Set Tables: https://developer.apple.com/metal/Metal-Feature-Set-Tables.pdf
- Metal resources / Metal Shading Language specification: https://developer.apple.com/metal/resources/
- Apple GPUs and tile-based deferred rendering: https://developer.apple.com/documentation/Metal/tailor-your-apps-for-apple-gpus-and-tile-based-deferred-rendering
- Metal 2 on A11 — imageblocks, tile shading, raster-order groups: https://developer.apple.com/videos/play/tech-talks/602/

Historical Apple GPU mapping should be checked against archived Apple OpenGL ES hardware tables and Imagination PowerVR documentation. PowerVR hardware opcode encodings are not treated as a stable Apple application compiler ABI.
