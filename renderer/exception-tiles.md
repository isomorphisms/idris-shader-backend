# Holomorphic / meromorphic exceptional-tile experiment

Portable semantics remain: evaluate the mathematical field and map the result to the canonical color/metadata interpretation.

Optional Apple path:

1. Evaluate f(z), phase, log|f| and cheap validity/variation data.
2. Retain useful intermediates in imageblock or threadgroup-local storage.
3. Use quad/SIMD/tile cooperation to classify a tile.
4. Ordinary tiles finish cheaply.
5. Exceptional tiles near zeros, poles, unresolved singularities, high local variation or failed conformality checks receive more samples, stronger diagnostics or more precision.
6. Feed the accepted mathematical result back into the same portable color semantics.

Potential local tests include phase winding, derivative estimates, Cauchy-Riemann residuals, zero/pole proximity and whether two nearby singular structures are resolved at the current sampling scale.

This file is deliberately an experiment note, not a claim that one particular criterion is already mathematically sufficient.
